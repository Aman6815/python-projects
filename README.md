# Python Beginner & Intermediate Projects

A collection of 10 Python projects built while learning and improving my Python programming skills.

This repository focuses on practical programming through projects, with each project introducing different concepts such as algorithms, data structures, problem solving, file handling, game logic, image processing, and text generation.

## Projects

| # | Project | Description | Main Concepts |
|---|---|---|---|
| 01 | [Mad Libs](./01-madlibs) | A word-based game that creates a funny story by asking the user for different types of words. | Strings, input, variables |
| 02 | [Rock Paper Scissors](./02-rock-paper-scissors) | A command-line game where the player competes against the computer. | Conditionals, loops, random |
| 03 | [Binary Search](./03-binary-search) | Implements binary search to efficiently find a value in a sorted collection. | Algorithms, lists, functions |
| 04 | [Guess the Number](./04-guess-the-number) | A number guessing game where the player tries to find a randomly selected number. | Random numbers, loops, validation |
| 05 | [Hangman](./05-hangman) | A word-guessing game where the player attempts to reveal a hidden word before running out of attempts. | Strings, lists, loops, game logic |
| 06 | [Tic-Tac-Toe AI](./06-tic-tac-toe-ai) | A Tic-Tac-Toe game that allows a player to compete against an AI opponent. | Game logic, algorithms, functions |
| 07 | [Minesweeper](./07-minesweeper) | A Minesweeper implementation where the player uncovers safe cells while avoiding hidden mines. | 2D data structures, recursion, game logic |
| 08 | [Sudoku](./08-sudoku) | A Sudoku program that works with the rules and solving logic of the classic puzzle. | Backtracking, recursion, algorithms |
| 09 | [Photo Editing](./09-photo-editing) | A Python-based photo editing project demonstrating programmatic image manipulation. | Python imaging, files, image processing |
| 10 | [Markov Chain Composer](./10-markov-chain-composer) | Generates new text by learning relationships between words in a source text. | Dictionaries, text processing, modules, testing |
